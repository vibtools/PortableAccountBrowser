# Project Analysis — v1.3.1

Portable Account Browser is a Windows-focused Tkinter launcher around a bundled Chromium runtime. SQLite stores profile metadata; each configured account receives an isolated Chromium user-data directory. Version 1.3.1 is a release-engineering update: application behavior remains unchanged while public packaging, source completeness, privacy scanning, release permissions, checksums, documentation, and GitHub readiness are hardened.
