# Roadmap

The roadmap is directional and does not guarantee release dates.

## Reliability

- Additional clean-machine Windows 10 and Windows 11 release testing
- Expanded recovery diagnostics for interrupted Chromium shutdowns
- More release-integrity checks

## User experience

- Optional profile icons
- Import/export of profile metadata without authenticated session data
- Accessibility and keyboard-navigation improvements

## Security and distribution

- Reproducible release documentation
- Optional Authenticode-signed official binaries
- Automated release attestation and checksum publication

## Community

- Additional provider presets based on user demand
- Translatable UI resources
- Contributor documentation improvements
