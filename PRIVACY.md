# Privacy Policy

Portable Account Browser is a local desktop application. It has no application-owned cloud service, analytics endpoint, advertising SDK, or telemetry collector.

## Data stored locally

The application stores profile metadata, Chromium browser data, website cookies, local storage, service-worker data, settings, logs, and downloads inside the extracted portable folder. Passwords are entered directly on third-party websites and are not collected by the launcher.

## Public releases

The publish-ready build pipeline rejects saved profiles, cookies, account databases, history, logs, downloads, and update backups. Only a clean public package should be uploaded to GitHub or another public platform.

## Third-party websites

Websites opened through the application operate under their own privacy policies and terms. This project does not control how those services process data.
