# Support

## Before opening an issue

1. Use the latest release.
2. Run the portable diagnostics.
3. Confirm the application folder is writable.
4. Remove email addresses, cookies, tokens, and private account information
   from screenshots and logs.

## Public support channels

- GitHub Issues: reproducible bugs
- GitHub Discussions: questions, ideas, and community support
- Vib Tools: <https://vib.tools/>
- More free open-source tools: <https://dev.vib.tools/>
- Free subdomain registration: <https://ygit.net>

Security vulnerabilities must be reported privately through GitHub Security Advisories.
