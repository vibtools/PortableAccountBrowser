# Portable Account Browser v1.3.1

## Highlights

- Portable Windows multi-account browser launcher
- Isolated Chromium profile directories
- Persistent website sessions
- Mailbox, Messaging, Social Media, Web Apps, and Custom groups
- Compact dark interface
- Single-tab profile reopening
- Clean public build with privacy and checksum verification
- Open-source MIT-licensed source code

## Release assets

- `PortableAccountBrowser_Windows_x64_v1.3.1_Public.zip`
- `PortableAccountBrowser_Source_v1.3.1.zip`
- SHA-256 checksum files
- Build report

## Security note

The official public ZIP contains no personal profiles, cookies, sessions,
browser history, personal downloads, or application logs.

## Windows warning

The binary may be unsigned. Windows SmartScreen can warn about unsigned or
newly published applications. Verify the SHA-256 checksum before running it.
